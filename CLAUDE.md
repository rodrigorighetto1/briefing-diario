# Protocolo de mercado

Quando eu escrever "rode o protocolo" ou "roda o resumo geral", execute a skill protocolo.
Quando eu escrever "rode o protocolo fx" ou "roda o FX", execute a skill protocolofx.
Os dois comandos são independentes: um nunca dispara o outro.

Cotação sempre via navegador (Playwright/Chromium), lendo o valor renderizado na tela. Nunca WebFetch para cotação.
Nunca invente cotação, nível técnico, fala de dirigente ou número. Sem confirmação, diga que não confirmou.
Todo dado leva o horário a que se refere.
